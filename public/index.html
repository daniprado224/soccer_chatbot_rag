⚽ Soccer Rules RAG

Ask a question about the IFAB Laws of the Game. This is a retrieval-augmented chatbot: it searches the actual rulebook text, has an LLM judge which passages are genuinely relevant, retries with a rewritten question if nothing relevant turns up, then answers citing the specific Law number(s) it used — or says it doesn't know, rather than guessing. See the README for the architecture and a full evaluation report.

How to read an answer

  1. Best way to ask a question is "X event happens when...".
  2. Answers cite Law numbers when confident — see the eval report for how often that citation is actually correct.
  3. "I don't know" is the correct response for out-of-scope questions.
  4. This demo runs on Google Gemini's free tier, shared across every visitor (see the tracker above and the README's "Design choices" section).
  5. Expand "Retrieval ranking" under an answer to see the actual scores used. When it can't answer, it also suggests a rephrasing that scores higher — a higher score means closer wording to the source text, not necessarily a better answer.
