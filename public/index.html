⚽ Soccer Rules RAG

Ask a question about the IFAB Laws of the Game. This is a retrieval-augmented chatbot: it searches the actual rulebook text, has an LLM judge which passages are genuinely relevant, retries with a rewritten question if nothing relevant turns up, then answers citing the specific Law number(s) it used — or says it doesn't know, rather than guessing. See the README for the architecture and a full evaluation report.

How to read an answer

  1. Answer cites Law numbers when it's confident — click through the README's eval report to see how often that citation is actually correct (spoiler: it's an honest, imperfect number, not a marketing one).
  2. "I don't know" is a deliberate, correct response for out-of-scope questions (ice hockey, refereeing salaries, etc.) — the pipeline is built to refuse rather than hallucinate.
  3. This demo runs on Google Gemini's free tier, shared across every visitor — see the tracker above and the README's "why Gemini, not Claude" section for why that means occasional pauses.
