# Scoped to what api/query.py (the spaCy-backend function) actually needs
# at request time -- deliberately excludes chromadb, pdfplumber, pytest,
# fastapi/uvicorn from the root requirements.txt (ingestion/eval/test
# tooling, not needed by the deployed function, and just add cold-start
# weight).
#
# `anthropic` is deliberately NOT listed here (unlike the root
# requirements.txt): this deployment runs LLM_BACKEND=gemini in
# production (Anthropic's API has no free tier and this account has no
# purchased credits -- see src/llm.py), so the Claude SDK is dead weight
# in a bundle it's never called from.
#
# IMPORTANT: if you ever set LLM_BACKEND=claude on THIS Vercel
# deployment, re-add anthropic here first -- otherwise `_call_claude()`'s
# `import anthropic` will fail at request time (caught by the existing
# error handling, but it'll misleadingly say "Google Gemini appears to
# be down" even though the real problem is a missing dependency).
#
# `fastembed` is NOT listed here either, even though this repo supports a
# minilm embedding backend -- that backend is its own separate Vercel
# function (api/minilm/query.py + api/minilm/requirements.txt), so THIS
# function never pays for fastembed/onnxruntime's weight. See
# src/webapp.py's docstring: bundling both backends into one function
# pushed it over Vercel's 500MB function size limit.
